📋 安装说明

  1. 下载 MoonTV Mac 版本压缩包
  2. 解压到 Downloads 目录：tar -xzf MoonTV-mac-*.tar.gz
  3. 移动到 Applications 目录：mv mac/MoonTV.app /Applications/
  4. 处理权限问题：sudo xattr -rd com.apple.quarantine /Applications/MoonTV.app
  5. 启动应用：open /Applications/MoonTV.app
